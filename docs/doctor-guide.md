# Website kaise edit karein

Ye guide clinic ke liye hai. Koi coding nahi aati beech mein.

## Login

1. `aapki-website.com/studio` kholein (phone ya laptop, dono par chalta hai).
2. **Google** (jis Gmail par invite aaya tha) ya **E-mail / password** chunein.
3. Left side mein saare sections dikhenge.

## Kuch bhi badalne ka tareeka

1. Left mein section chunein, jaise **Home page** ya **Gallery**.
2. Text ya photo badlein.
3. Neeche **Publish** dabayein. Publish ke bina website par kuch nahi badlega.
4. Website 1 minute ke andar update ho jaati hai.

Galti ho gayi? Publish se pehle **Discard changes** se badlav hata sakte hain. Publish ke baad, document ke upar ke menu mein **Review changes / History** se pichhle kuch dino ka version wapas la sakte hain (free plan mein history kam dino ki hoti hai, isliye bade badlav se pehle text kahin copy kar lein).

## Aam kaam

| Kaam | Kahan |
|---|---|
| Gallery mein photos daalna | **Gallery & before/after → Photos**. Ek saath kai photos drag karke daal sakte hain. Har photo par category (Clinic, Team…) chunein. |
| Photo badalna | Photo par click → **Replace**. |
| Photo ka main hissa set karna | Photo par click → crop icon → chehre ya daant par gol nishaan rakhein. |
| Home page ka banner | **Home page → Top banner** |
| Home page ke sections aage-peeche karna | **Home page → Sections**. Row ko pakad kar drag karein. Kisi section ko chhupane ke liye usme **Show this section** band karein. |
| Timings / chhutti | **Clinic details → Timings**. Chhutti ka notice: **Clinic tab → Notice bar** on karein. |
| Booking WhatsApp number | **Clinic details → Phone & WhatsApp** |
| Naya treatment | **Treatments → +** (upar). Title likh kar **Page address → Generate** dabayein. |
| Google review copy karna | **Patient reviews → Add item** |
| Before/after photo | **Gallery & before/after → Before / after**. Sirf patient ki permission ke baad, aur "Patient has given permission" tick karna zaroori hai. |

## Dhyan rakhein

- Photo ke saath **"What is in the photo?"** zaroor bharein. Isse Google par clinic aasani se milta hai.
- Bahut badi photo bhi chalegi, website use apne aap chhota kar deti hai.
- Design (rang, layout) yahan se nahi badalta. Wo developer ke paas hai, taaki galti se site na bigde.
